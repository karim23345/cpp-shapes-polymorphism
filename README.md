# C++ Shapes Calculator

A console-based C++ application for calculating and displaying geometric properties of circles and cylinders.

## Features
- Create circle and cylinder objects using user input.
- Calculate circle area and cylinder total surface area.
- Display shape properties, including coordinates, radius, and height.
- Handle different shapes through base-class pointers.

## Concepts Practiced
- Object-Oriented Programming (OOP)
- Inheritance
- Runtime Polymorphism
- Virtual Functions and Method Overriding
- Constructors
- Dynamic Memory Allocation

## Technologies
- C++

## Purpose
This project was developed as a practical exercise in applying object-oriented programming concepts to a simple geometry-based application.
